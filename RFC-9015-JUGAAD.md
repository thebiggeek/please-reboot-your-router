## Abstract

This document defines the Jugaad Universal Gateway Adjustment & Adaptation
Directive (JUGAAD), a standardized operational framework where temporary,
improvised, unsupported, and scientifically questionable fixes become permanent
network deployment architecture.

JUGAAD prioritizes adaptation over engineering and ensures that customers
modify their homes, furniture, walls, airflow patterns, and lifestyle habits
instead of the ISP improving network infrastructure.

---

## 1. Introduction

Customers may report:

* Weak WiFi signal
* Packet loss
* Dead zones
* Slow throughput
* Unstable roaming
* Random disconnects
* Poor indoor coverage

JUGAAD defines that such issues MUST be resolved through environmental
adjustments instead of technical improvements.

## 5. Bandwidth Adjustment & Wireless Alignment Logic

JUGAAD defines WiFi propagation as dependent on environmental,
architectural, emotional, and airflow-related variables collectively
known as the Bandwidth Adjustment & Wireless Alignment Logic (BAWAL) model.

Under BAWAL, wireless performance MUST be treated as a customer-managed
phenomenon rather than an infrastructure limitation.

The following propagation variables are considered operationally critical:

| Environmental Variable | Signal Impact         |
| ---------------------- | --------------------- |
| Open doors             | Excellent             |
| Closed doors           | No signal             |
| Thick walls            | Customer fault        |
| Ceiling fan speed      | Throughput multiplier |
| Sofa position          | Latency               |
| Human movement         | Packet loss           |
| Positive attitude      | Stability             |

Technicians implementing BAWAL using JUGAAD MAY additionally recommend:

* Standing closer to router
* Rotating ONT toward hallway
* Keeping windows permanently open
* Reducing furniture density
* Avoiding steel utensils near WiFi equipment
* Maintaining cooperative mindset during diagnostics

Enterprise deployments MAY include:

* Router balancing on flower pot
* ONT suspended using tape
* LAN cable through bathroom window

Signal degradation MUST NOT be considered an ISP responsibility
until all customer-adjustment procedures have been exhausted.
