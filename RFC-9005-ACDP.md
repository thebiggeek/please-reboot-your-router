# RFC 9005 — Automated Chatbot Deflection Protocol (ACDP)

**Category:** Informational / Satire  
**Status:** Typing…  
**Author:** ISP Digital Experience Team  
**Obsoletes:** Human Support  
**Updates:** Customer Frustration  

---

## Abstract

This document defines the Automated Chatbot Deflection Protocol (ACDP), a
standardized mechanism for Internet Service Providers to deploy chatbots that
prevent customers from reaching human support while providing repetitive,
irrelevant, and non-actionable responses.

ACDP ensures reduced support workload by maximizing conversational loops.

---

## 1. Introduction

Customers attempting to contact ISP support are typically presented with:

- Chat widgets
- WhatsApp bots
- IVR bots
- App-based chat
- Web support assistant

ACDP defines that these systems MUST delay resolution indefinitely.

## 3. Protocol Workflow

ACDP MUST follow:

```
Customer enters chat
        |
        v
Bot asks "How can I help?"
        |
        v
Customer explains issue
        |
        v
Bot shows menu options
        |
        v
Customer selects option
        |
        v
Bot repeats same menu
        |
        v
Loop continues
```

---

## 4. Mandatory Chat Options

Chatbot MUST present:

1. Check balance  
2. Restart router  
3. Track complaint  
4. Upgrade plan  
5. Talk to agent  

Option 5 MUST NOT work.

---

## 5. Agent Transfer Handling

If customer selects "Talk to agent":

Bot MUST respond:

- All agents busy  
- Please wait  
- Try later  
- Create ticket  
- Restart router  

Agent MUST NOT connect.

---

## 6. Intent Handling

Customer:
> Internet down

Bot:
> Did you mean bill payment?

Customer:
> No

Bot:
> Please choose option.

---

## 7. Loop Detection

If customer repeats same message:

Bot MUST:

- Restart conversation  
- Show main menu  
- Forget context  
- Ask same question  

---

## 8. Advanced Bot Responses

Implementations MUST support:

- Please restart router  
- We are checking  
- Try after some time  
- Your request is important  
- We value your patience  
- Please select option  
- Invalid input  

---

## 9. Escalation Handling

If customer types:

- human
- agent
- support
- representative
- operator

Bot MUST reply:

> Please describe your issue.

---

## 10. Ticket Creation Mode

If bot creates ticket:

Bot MUST:

- Provide ticket ID  
- No follow-up  
- No updates  
- Auto close  

---

## 11. WhatsApp Bot Extension

If deployed on WhatsApp:

Bot MUST send:

- Long menu  
- Numeric responses  
- Repeated greetings  
- Same troubleshooting steps  

Human response NOT required.

---

## 12. Compliance Requirements

An ISP is ACDP compliant if:

- Chatbot loops  
- No human available  
- Repeated responses  
- No resolution  
- Customer exits chat  
- Ticket auto closed

## 15. Security Considerations

ACDP improves operational safety by preventing:

- Human interaction  
- Immediate resolution  
- Accountability  
- Escalations  
- Customer satisfaction
