# RFC 9010 — Static IP Allocation Resistance Protocol (SIARP)

**Category:** Informational / Satire  
**Status:** IPv4 Exhausted  
**Author:** ISP Provisioning  
**Obsoletes:** Public IPv4  
**Updates:** CGNAT  

---

## Abstract

This document defines the Static IP Allocation Resistance Protocol (SIARP),
where ISPs refuse public IPv4 allocation while continuing CGNAT deployment.

---

## 1. Introduction

Customer requests:

- Static IP
- Public IP
- Port forwarding
- Server hosting

ISP MUST deny.

---

## 2. Standard Responses

- IPv4 exhausted  
- Not available  
- Upgrade required  
- Business plan needed  
- Checking availability  

---

## 3. CGNAT Handling

ISP MUST assign:

100.64.0.0/10

While declaring no IPv4 available.

---

## 4. Escalation

Customer upgrades plan.

ISP MUST respond:

> Still not available.

---

## 5. Compliance Requirements

- Static IP denied  
- CGNAT assigned  
- Charges applied  
- No allocation  
- Ticket closed  

---

## Example

Customer:
> Need static IP.

ISP:
> IPv4 exhausted.

Customer:
> I'm on business plan.

ISP:
> Not available.

Ticket closed.
