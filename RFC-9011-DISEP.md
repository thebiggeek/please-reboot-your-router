## Abstract

This document defines the Dynamic IP Stability Enhancement Protocol (DISEP),
a standardized mechanism where ISPs claim that dynamically assigned IP
addresses provide superior physical link stability compared to statically
assigned IP addresses.

DISEP establishes a direct relationship between DHCP lease allocation and
fiber signal integrity.

---

## 1. Introduction

Customers may report:

* Link flapping
* PPPoE reconnects
* Fiber drops
* Packet loss
* ONT rebooting
* Optical LOS alarms

If customer is using static IP allocation, ISP MUST attribute instability
to the static IP itself.

---

## 2. Core Principle

DISEP defines:

```
Static IP = Fixed packets
DHCP IP = Flexible packets
Flexible packets = Better stability
```
